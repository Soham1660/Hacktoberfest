# Design Context: PR Checker

The authoritative design specification is [design.md](design.md). Design tokens live in `src/pr_checker/web/css/tokens.css`.

**Audience.** Open-source maintainers triaging pull requests (especially during Hacktoberfest), and reviewers who want a second reader that checks intent against implementation.
**Job.** Decide quickly whether a PR does only what its description says, and see exactly which lines don't match, with evidence they can check.
**Tone.** Calm, exact, trustworthy. A review desk, not an alarm panel and not a marketing site.

**System in one paragraph.** Neutral light theme (dark follows the OS). IBM Plex Sans for UI, Plex Mono for code and identifiers, Plex Serif only for the verdict headline and PR title. Color is reserved for meaning: concern level, covered changes, diff add/delete, links and focus. No gradients, shadows, glass, decorative charts, or emoji icons. Motion only for state changes, and it respects `prefers-reduced-motion`.
